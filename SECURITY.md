# Security reports

Report suspected security vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/sirkuttin/GROUT/security/advisories/new). Please include the GROUT version, reproduction steps and expected impact. Do not post credentials, personal app-library files or exploit details in public issues.

For ordinary bugs, use [GitHub Issues](https://github.com/sirkuttin/GROUT/issues).

GROUT is an early-stage Windows utility. Downloads are currently unsigned. Release assets have SHA-256 checksums; the self-updater checks stable releases from `sirkuttin/GROUT` and verifies the matching checksum before replacement. Automatic checks do not silently install updates: replacement requires confirmation. Keep the EXE in a folder you can write to. Protected installation locations may require a manual update.
