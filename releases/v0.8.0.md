### D2RLoader mods and patches

- Paste an individual D2RLoader mod-page URL or its detail API URL into Add App. Both map to the same source.
- Browse D2RLoader provides API-backed search and a paginated catalog; selecting a mod fills its source link.
- Published release versions, changelogs, loader requirements and provider scan warnings are retained.
- Downloads use the release-ID endpoint with SHA-256 and exact-size verification.
- ZIPs use the existing visual folder/file selector and remembered update mapping. Standalone DLL/JSON files use manual download handling.
- D2RLoader installed versions come from the version suffix in the top-level manifest.json name.
- Installed mod folders use stable names without version suffixes. Saved ZIP selections can follow unique version-renamed folders, and nested manifests remain the exact version source.
- Uninstall targets the mod folder written by GROUT rather than a shared plugins parent.
- Source-specific rate-limit pauses survive restart.
- Improved failed self-update filename-migration cleanup when Windows briefly retains an executable lock.

Nexus remains disabled in public builds. GROUT remains a single EXE under 1 MB.
