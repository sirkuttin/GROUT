### One stable filename

Download **GROUT.exe**. Future updates keep this filename; the version is shown inside the app and in file properties.

- Self-updates from older versioned EXE names migrate to `GROUT.exe` in the same folder. Matching startup, desktop, Start menu and taskbar shortcuts are updated after startup succeeds. Custom shortcuts elsewhere may need manual adjustment.
- An existing `GROUT.exe` is never overwritten by filename migration: the updater stops before closing the old instance if there is a conflict.
- The versioned compatibility asset is the same binary, provided so GROUT 0.5.0 updaters can reach this release. New downloads should use **GROUT.exe**.

### GROUT now has its own icon

A new teal G icon appears on the executable, taskbar, tray and app windows. The vector source and multi-size icon generator are included in the repository.

### Red-team fixes included

- Keep the self-update rollback copy until the new app confirms successful startup; roll back if it exits early or fails to become ready.
- Protect tracked installation and version-source paths from cache cleanup.
- Require application identity as well as folder identity before selecting a registered Windows uninstaller.
- Reject ZIP updates that would overwrite a newly appeared destination file without a backup.
- Validate extracted ZIP byte counts and CRC, and stop known-size downloads when they exceed the expected length.
- Verify release tags resolve to the tested source commit before publishing.

### Validation

The full packaged regression suite covers normal and failed-start self-updates, stable-filename migration, rollback, startup/shortcut path repair, corrupted archives, concurrent destination creation, cleanup protection and uninstall identity checks. Windows x64, single portable EXE; unsigned. Existing library and settings carry over.

Additional hardening: uninstall paths reject junction ancestors, attached-quote MSI uninstall commands are handled correctly, and invalid/non-PE portable EXEs are rejected before replacement.
