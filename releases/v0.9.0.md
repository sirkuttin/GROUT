### Website downloads and reliable installed-version tracking

- Add apps from a public website using the page URL and its current download URL. GROUT checks matching versioned links for newer releases, including FrameDrop-style installer links.
- Website sources use the usual scheduled checks, installers, portable EXE replacement and ZIP extraction. Both URLs can be edited in App settings.
- ZIP installs, portable EXE copies and located installer installations now remember the applied release when no usable version is supplied. Small fallback JSON records stay in GROUT’s AppData folder, away from managed app files.
- Fallback records survive restarts and update after successful installations. Failed operations do not advance the installed version; missing app files still trigger an alert.
- Native version detection resumes when a usable version source becomes available, and the fallback record is deleted. Unchanged stale manifests left by an older ZIP do not override the newly installed release.
- Installer failure/cancellation exit codes no longer count as successful installation.

Website tracking currently requires a public HTTPS page with a version number in the download URL. JavaScript-only links and fixed latest-download URLs are not supported. Nexus remains disabled in public builds.

Validated with the packaged regression suite, including 24 website-source and 15 installation-record checks. GROUT remains a single EXE under 1 MB.
