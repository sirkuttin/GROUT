### More reliable installation tracking

- Remember the Windows installation entry selected during setup and reuse it for updates and uninstall.
- Recognize installer registrations by their installation folder, including D2R PCVR when Windows lists it as D2R VR Unleashed.
- Complete first-time setup for registered installations that use an executable in a runtime subfolder.
- Remove the routine successful installation-discovery message.

The packaged regression suite covers registration persistence, first-time installation matching, uninstall lookup, and ambiguous or unrelated installations.
