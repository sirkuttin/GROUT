### Choose exactly what to install from a ZIP

- Choose ZIP contents downloads and inspects the archive, then displays a visual folder tree.
- Install the whole ZIP, the contents of one folder, or a single file. A selected folder's contents go directly into the configured app folder without nesting that folder again.
- Nothing is installed while browsing. Cancelling preserves the previous choice.
- The selection is saved for future updates. Missing/renamed items stop the update before installed files change.
- First-time installs reuse the inspected ZIP, verify its hash, and extract from the archive again before applying files.
- Existing automatic overwrite behavior is retained, with internal transient rollback and cleanup. No conflict-review screen was added.
- Long sidebar labels no longer create horizontal scrolling.

### Nexus Mods remains in testing

Nexus integration is disabled in this public release pending application registration. Test-build Nexus entries remain in the library, but make no Nexus API requests. GitHub, Codeberg and GitLab continue to work normally.

The full packaged regression suite includes visual picker confirm/cancel flows, folder/file mappings, archive reuse and cleanup, as well as checks that the public build cannot contact Nexus. The app remains a single EXE under 1 MB.
