### GROUT now updates itself

- Checks stable releases from this public GitHub repository on startup and daily. Manual **Check GROUT updates** is always available; automatic checks can be disabled in Settings.
- When a newer Windows x64 release is available, choose **Update and restart**. GROUT verifies the release checksum, closes its running instance, replaces its EXE and restarts at the same path. Library and settings carry over.
- A temporary rollback copy protects executable replacement and immediate launch failures. Successful restarts remove update payloads. Protected folders may require manual updating; GROUT does not silently elevate.
- The repository is now public and MIT licensed. The portable EXE embeds GROUT and bundled-runtime notices; Settings includes a license viewer. Combined license notices are also attached to releases.
- New portable ZIP installs automatically create an app-named subfolder inside the chosen parent folder.

### First install or upgrade from 0.4.x

Download **GROUT-0.5.0-win-x64.exe** and save it to a permanent writable folder. You may rename it to `GROUT.exe`. Close the old instance before this first launch; older builds do not yet contain the self-updater. Existing settings and tracked apps are retained. If Windows startup was enabled, toggle it off/on in Settings after changing the executable path.

Windows x64 only; one self-contained portable EXE with no adjacent DLLs or separate .NET installation required. The EXE is unsigned. GitHub CLI and authentication are not required for self-updates.

### Validation

The packaged regression suite passed, including checksum/corrupt-payload rejection, version selection, replacement/rollback and a real stop/replace/restart smoke test using isolated copies of GROUT. Public GitHub update checks were verified without credentials. Real third-party installer/uninstaller execution and Windows notification delivery remain manual tests.
