### Direct installation and updates

- ZIP installs and updates now extract directly into the configured app folder. There is no update-review or file-conflict screen.
- Files included in the archive overwrite matching files, including settings files. Files absent from the archive remain unchanged; archive structure is preserved.
- Portable EXE replacements also proceed directly without an overwrite-review screen.
- Temporary rollback happens internally during file writes and is removed after successful completion. There is no backup setup or backup/apply step.
- Unsafe/corrupt archives and invalid portable EXEs are still rejected before applying files.

The full packaged suite includes fresh ZIP installs, conflicting first installs, updates, automatic settings overwrite, absent-file preservation, temporary cleanup and portable overwrite with no review calls. Existing library and settings carry over.
