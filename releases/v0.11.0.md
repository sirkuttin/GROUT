### Dependable operations and a cleaner library

- Cancel release-check batches from the Check now button without losing completed results or changing unchecked items.
- Stop waiting for external installers without terminating them or claiming successful installation. Unconfirmed state and needed packages remain available.
- Recover from damaged library/settings with the affected file, Open data folder, validated Retry loading and Exit. Existing files are preserved; damaged installation records retain the last recorded version.
- Keep unsaved manual-version drafts through background refreshes. Version-check errors and app progress/failures appear beside the relevant app; routine success footer messages are reduced.
- Click anywhere on group headers to expand/collapse them without a group detail page. Right-click and hover/focus overflow menus offer matching actions and row selection. Outside dismissal uses a click shield to prevent activating underlying controls.
- Resize the sidebar with a divider; the chosen width is remembered. App titles use the top row, status sits below, and header controls align with counts.
- Choose Keep running in the tray or Exit GROUT for window close behavior. Tray remains the compatible default; active operations and dialogs guard against unsafe exit.
- Added keyboard branch navigation and clearer accessible names. Search and Updates only are temporarily hidden, reclaiming their entire row; D2RLoader browsing and public Nexus integration remain disabled.
- Restored G.R.O.U.T. branding and Filling the gaps in app updates.

The packaged regression suite covers cancellation, installer detachment, configuration recovery, menu/row interactions, persistence and simulated accessibility/layout cases. Actual screen-reader, complete keyboard-focus and multi-monitor/DPI validation remain incomplete and are tracked as known limitations. User testing confirmed the revised menu-dismissal and overflow-opening behavior; this does not establish those broader accessibility results.

Windows x64 remains a single portable EXE under 1 MB using Windows .NET Framework 4.8. No additional runtime DLLs are bundled.
