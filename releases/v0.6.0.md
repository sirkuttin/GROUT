### GROUT under 1 MB

- GROUT now uses .NET Framework 4.8, supplied by Windows 11, instead of bundling .NET 10.
- The download remains a single portable Windows x64 EXE, with no adjacent DLLs, config file or runtime installation needed on Windows 11.
- Existing app libraries, settings and updater plans remain compatible. The WPF interface is retained.
- Modern-only APIs were replaced with Framework-compatible JSON, process, hashing, native folder-picker and file-operation code. ZIP CRC/path checks, executable validation, atomic writes and self-update rollback remain enabled.
- Release builds enforce an EXE size below 1,000,000 bytes.

The full packaged regression suite passes, including new old-format JSON/date/record compatibility tests and isolated self-update restart/rollback scenarios.
