### Repository links and moves

- The selected app shows its full repository URL below its name as a clickable link.
- Edit **Repository URL** in App settings when a project moves, including between GitHub, Codeberg and GitLab.
- GROUT verifies the new project before saving and rejects duplicate tracked sources. Installed files, update destination and installed version are kept. Old release/download selections are cleared so you can choose a package from the new source.

### App naming fix

- A shared parent folder no longer supplies the name of an unrelated EXE.
- Automatically suggested names refresh when the install location changes and remain automatic after saving. Deliberately entered custom names are preserved.
- **Use detected name** clears a previously saved override. Older overrides are preserved until explicitly reset because GROUT cannot distinguish an intentional custom name from an old automatic suggestion.
- Switching from tracking an existing app to a fresh install clears the old location fields.

The packaged regression suite includes shared-folder naming, custom-name preservation/reset, provider migration, duplicate-source rejection and the real settings save flow. Existing library and settings carry over.
