GROUT now detects missing installations automatically, including apps uninstalled outside GROUT.

- Checks saved app locations whenever the window regains focus and every minute while running, including manual version tracking.
- Shows an amber **App not found** banner and sidebar status, with **Find installation** and **Stop tracking** as the main actions.
- Disables update, uninstall and version editing while the installation is missing. Clears stale success messages and labels the retained version as **Last known version**.
- Find installation offers matching Windows installed-app entries or browsing to the current EXE/folder. Restoring a valid location clears the warning.
- Adds the C# release script used to build, test, checksum, push and publish this release.

### Download

Download **GROUT-0.4.8-win-x64.exe** and run it. Windows x64; a single portable EXE with .NET included, with no adjacent DLLs required. Close the previous instance first. Your library and settings carry over. The executable is unsigned. If startup was enabled, toggle it off/on in Settings after moving the executable.

### Validation

The packaged full regression suite passed, including 10 missing-installation assertions. The missing-app screen was rendered and visually inspected. Test results and SHA-256 checksums are attached. Real third-party installer/uninstaller execution is not covered by automated tests.
